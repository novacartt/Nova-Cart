# 🚀 Nova Cart - Buy Now Pay Later Platform

## 📋 Overview
Nova Cart is a technology-driven EMI financing platform designed to make purchasing consumer products more affordable, convenient, and transparent. Built with modern web technologies and Firebase backend.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript (ES6)
- **Backend:** Firebase Authentication, Firestore Database, Firebase Storage
- **Icons:** Font Awesome 6
- **Fonts:** Google Fonts (Inter)
- **PWA:** Manifest & Service Worker support
